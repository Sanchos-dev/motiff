# WIP Motiff

Motiff is an open-source music player for linux with simple ui. 
What do you want? it's just a player

Motiff supports:
- [x] local m3u/m3u8 playlists
- [ ] m3u/m3u8 playlists (http music streaming like internet radio)
- [x] .mp3
- [x] .aac
- [x] .m4a
- [x] .ogg
- [x] .wma
- [x] .opus
- [x] .flac
- [x] .wav
- [x] .ape
- [x] .aiff
